# kerntau

信息安全技术 · Web 开发 · 工具构建

</div>

我在这里记录信息安全、全栈开发和个人工具项目。仓库内容覆盖 TypeScript/React/Vue 前端、Go 服务、数据存储与自动化脚本，欢迎通过 GitHub 交流。

## 关注方向

- Web 应用与静态站点
- TypeScript、React、Vue、Next.js、Vite
- Go、PostgreSQL、Redis
- 信息安全与工程实践
- 面向个人工作流的小型工具

## 代表性仓库

- diary：Markdown 日记系统
- moments：轻量朋友圈
- blog-v3：React + Rsbuild 博客引擎
- Trace：博客与内容平台 monorepo
- openai-agents-starter-node：OpenAI Agents SDK 示例
